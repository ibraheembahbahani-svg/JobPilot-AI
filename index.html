Profile security

This starter stores its data in localStorage, which is not suitable for sensitive records or production multi-user accounts.

  • Production: account-based access controls
  • Encrypted file storage and audit logging
  • Separate user data by authenticated user ID
  • Explicit retention and deletion controls
  • Do not store job-board passwords

Production safety gates

Before enabling real-world submissions, JobPilot AI will require:

  • Explicit user-authorized application rules
  • Verified job data and deduplication
  • Truthful, user-approved screening answers
  • Permitted site access or partner APIs
  • Automatic pause on unknown questions
  • Per-user rate limits and kill switch
